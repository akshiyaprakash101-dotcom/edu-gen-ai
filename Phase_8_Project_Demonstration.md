# Phase 8: Project Demonstration Phase

## Live Project Link
* **Live Web Application:** [EduGenie on Render](https://edu-gen-ai.onrender.com)
* **Public GitHub Repository:** [akshiyaprakash101-dotcom/edu-gen-ai](https://github.com/akshiyaprakash101-dotcom/edu-gen-ai)

## Core Capabilities Demonstrated
1. **Interactive Q&A:** Accepts natural language questions and provides real-time AI responses.
2. **Concept Explanations:** Formats complex academic topics into accessible breakdowns.
3. **Text Summaries:** Condenses input passages into structured summary notes.
4. **Interactive Quiz Engine:** Dynamically generates multiple-choice quizzes with client-side automated grading and instant feedback.
